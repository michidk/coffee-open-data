# Proposal: expand coffee taxonomy catalogs

## Why

Roastbook’s controlled values cover the equipment types, brew methods, processing methods, and coffee varieties needed to describe real coffee setups. The initial catalogs were too small for useful imports.

## What Changes

- Expand all four taxonomy catalogs with Roastbook-inspired values.
- Add concise descriptions and aliases where a name has common alternatives.
- Keep IDs stable, lowercase, and kebab-case so records can reference them safely.
